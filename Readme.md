# Репозиторій лабораторних робіт з дисципліни «Теорія і методи обчислювального інтелекту»

## Опис дисципліни
Цей репозиторій містить практичні та лабораторні роботи, виконані в межах вивчення курсу з обчислювального інтелекту. Основна увага приділяється проєктуванню, розробці та застосуванню інтелектуальних систем для розв'язання прикладних задач. Під час курсу розглядаються методи машинного навчання (з учителем та без учителя), алгоритми нечіткої логіки для роботи в умовах невизначеності, а також архітектури штучних нейронних мереж. Репозиторій демонструє повні цикли обробки даних: від очищення та підготовки датасетів до побудови, налаштування та об'єктивної оцінки моделей.

## Представлені роботи

### Лабораторна робота №1: Аналіз та прогнозування енергоспоживання
Робота демонструє повний цикл обробки даних та побудови моделей машинного навчання. Включає вирішення задач регресії та класифікації, налаштування гіперпараметрів моделей та порівняння їхньої ефективності.

### Лабораторна робота №2: Кластеризація
Робота присвячена методам машинного навчання без учителя. Виконується розбиття даних на кластери для пошуку прихованих закономірностей та групування об'єктів за їхніми характеристиками.

### Лабораторна робота №3: Нечітка логіка та проєктування інтелектуального модуля
* **Мета:** Ознайомитися з принципами нечіткої логіки та її застосуванням для проєктування інтелектуального модуля, здатного приймати рішення в умовах невизначеності.
* **Опис:** Розроблено модуль для виявлення схожих записів у базі даних нерухомості Парижа. Система аналізує текстові дані (опис та адресу) для групування об'єктів, які ймовірно є ідентичними, попри орфографічні помилки чи різні формати запису.
* **Методи:** Для оцінки схожості використовуються алгоритми Jaro-Winkler (текстові перестановки), Soundex (фонетична схожість) та Damerau-Levenshtein (редакторська відстань).

### Лабораторна робота №4: Основи нейронних мереж (побудова та навчання перцептрона)
* **Мета:** Ознайомитись з поняттями штучних нейронних мереж, їхньою архітектурою, принципами навчання.
* **Опис:** Робота охоплює побудову та навчання нейронних мереж (від одношарового до багатошарового перцептрона) для вирішення задач бінарної класифікації. Продемонстровано застосування сучасних практик глибокого навчання, оптимізації та запобігання перенавчанню.

**Практична реалізація: Classification of Raisin Varieties Using Deep Learning (PyTorch)**
Проєкт є практичною реалізацією побудови багатошарового перцептрона (MLP) для розв'язання задачі бінарної класифікації з використанням фреймворку PyTorch. Модель аналізує числові (геометричні) ознаки родзинок з набору `variant2-raisin.csv` та класифікує їх на два сорти: *Kecimen* (Клас 0) та *Besni* (Клас 1).

**Головні особливості (Features):**
* **Кастомний Dataset та DataLoader:** Подача даних батчами для ефективного навчання.
* **Глибока архітектура (MLP):** 4 приховані шари з поступовим зменшенням розмірності.
* **Стабілізація:** Використання шарів `BatchNorm1d` та `Dropout` для запобігання перенавчанню (overfitting).
* **Порівняння оптимізаторів:** Одночасне тренування та порівняння 5 конфігурацій (Adam, SGD + Momentum, RMSprop, L1 та L2 регуляризації).
* **Розумне навчання:** Реалізовано динамічну зміну кроку навчання (`ReduceLROnPlateau`) та ранню зупинку (`Early Stopping`).
* **Оцінка (Metrics):** Автоматичний вибір найкращої моделі, обчислення Accuracy, Precision, Recall, F1-score та побудова ROC-кривої (AUC).

### Лабораторна робота №5: Згорткові нейронні мережі (CNN) та Transfer Learning
* **Мета:** Ознайомитися з архітектурою згорткових нейронних мереж та передовими методами перенесення знань (Transfer Learning) для розв'язання задач комп'ютерного зору (Computer Vision).
* **Опис:** Робота присвячена побудові системи багатокласової класифікації зображень (на прикладі розпізнавання 20 різних франшиз/стилів аніме з використанням фреймворку PyTorch). Продемонстровано повний цикл підготовки візуальних даних та порівняння різних архітектурних підходів.

**Підготовка набору даних (Dataset):**
Дані організовані у стандартному форматі для `ImageFolder`. Головна папка містить вкладені папки з назвами класів (аніме), а в них — відповідні зображення.Перед запуском коду шлях до датасету вказується у змінній `data_dir`.

**Архітектурні рішення:**
1. **Власна згорткова нейромережа (Custom CNN):** Написана з нуля базова мережа з трьох згорткових блоків (Conv2d -> BatchNorm2d -> ReLU -> MaxPool2d). Головною особливістю є використання `AdaptiveAvgPool2d` (Global Average Pooling) замість класичного шару Flatten, що дозволило суттєво зменшити кількість вагових коефіцієнтів та уникнути перенавчання.
2. **Transfer Learning (Feature Extraction):** Використання попередньо навченої на ImageNet моделі ResNet18 із повністю замороженою згортковою базою (тренується лише новий фінальний класифікатор).
3. **Transfer Learning (Fine-Tuning):** Додаткове розморожування останнього блоку (`layer4`) моделі ResNet18 із мікро-кроком навчання (`lr=0.0001`) для адаптації складних візуальних фільтрів під специфічну рисовку аніме.

**Аналіз результатів:**
Методи Transfer Learning (особливо Fine-Tuning) значно перевершують власну CNN за швидкістю збіжності та підсумковою точністю на валідаційній вибірці. Матриця помилок підтверджує, що модель успішно знаходить глибинні патерни, плутаючись лише у візуально схожих франшизах.

### Лабораторна робота №6: Аналіз тональності тексту на наборі даних IMDB
* **Мета:** Дослідження нейромережевих архітектур BiLSTM, 1D-CNN та механізмів Attention для задачі бінарної класифікації тексту (визначення позитивних та негативних відгуків на фільми). Експерименти проведено на повному наборі даних IMDB (50 000 записів).

**Структура та етапи розробки:**
* **Попередня обробка даних:** Завантаження 25 000 тренувальних та 25 000 тестових записів. Побудова словника токенів із фільтрацією за частотністю (мінімум 5 входжень).
* **Базова модель BiLSTM:** Реалізація двонаправленої рекурентної мережі з двома шарами LSTM та Dropout для регуляризації.
* **Згорткова мережа (1D-CNN):** Використання паралельних згорткових фільтрів різних розмірів (3, 4, 5) для пошуку локальних емоційних патернів у тексті.
* **Механізм Уваги (Self-Attention):** Інтеграція шару уваги в LSTM для покращення роботи з довгими реченнями та візуалізація ваг уваги у вигляді теплових карт.
* **Transfer Learning:** Експериментальне порівняння результатів при використанні заморожених векторів GloVe та Word2Vec.

**Основні результати експерименту:**
* **Найкраща архітектура:** Одновимірна згорткова мережа (1D-CNN) продемонструвала найвищу точність (>84%) та найменшу схильність до перенавчання.
* **Роль Attention:** Механізм уваги суттєво підвищив якість роботи LSTM (з 69% до 80%), дозволивши моделі фокусуватися на ключових словах-маркерах.
* **Обмеження Transfer Learning:** Використання універсальних попередньо навчених словників без донавчання (Fine-tuning) показало низьку ефективність (54-60%), що доводить необхідність адаптації векторів під специфічний домен кіноввідгуків.

### Лабораторна робота №7: Навчання з підкріпленням (побудова інтелектуальних агентів)
* **Мета:** Розробка інтелектуального агента для керування класичною фізичною системою Acrobot-v1. Робота містить покрокову реалізацію алгоритму Deep Q-Network (DQN) на базі PyTorch для навчання дволанкового маніпулятора мистецтву розгойдування.

**Про середовище Acrobot:**
Acrobot — це віртуальний робот-гімнаст, що складається з двох ланок. Тільки шарнір між ланками має мотор, тоді як точка кріплення ("плече") вільна. Завдання полягає у розгойдуванні системи так, щоб нижній край піднявся вище горизонтальної лінії. Оскільки система є "недоактюованою", необхідно використовувати інерцію та фізику маятника.

| Параметр | Опис |
| :--- | :--- |
| **State Space** | 6 неперервних значень (cos/sin кутів та кутові швидкості) |
| **Action Space** | Discrete(3): 0 (ліворуч), 1 (нічого), 2 (праворуч) |
| **Винагорода** | -1 за кожен крок до моменту досягнення цілі |
| **Умова завершення** | Підйом вільного кінця вище лінії або 500 кроків |

**Результати навчання:**
Завдяки алгоритму DQN, агент проходить шлях від хаотичних рухів (середня винагорода -500) до ідеальної стратегії, де завдання виконується за мінімальну кількість кроків (середня винагорода стабілізується на рівні -80...-120).
