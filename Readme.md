# Навчання з підкріпленням: побудова інтелектуальних агентів

Ласкаво просимо до проєкту з розробки інтелектуального агента для керування класичною фізичною системою **Acrobot-v1**. Цей репозиторій містить покрокову реалізацію алгоритму Deep Q-Network (DQN) на базі PyTorch для навчання дволанкового маніпулятора мистецтву розгойдування.

---

## Про Проєкт: Що таке Acrobot?

Acrobot — це віртуальний робот-гімнаст, що складається з двох ланок. Тільки шарнір між ланками має мотор, тоді як точка кріплення ("плече") вільна.
* **Завдання:** Розгойдати систему так, щоб нижній край піднявся вище горизонтальної лінії.
* **Виклик:** Система є "недоактюованою" (underactuated) — ви не можете просто підняти її вгору, ви мусите використовувати інерцію та фізику маятника.

## Технічні характеристики середовища

| Параметр | Опис |
| :--- | :--- |
| **State Space** | 6 неперервних значень (cos/sin кутів та кутові швидкості) |
| **Action Space** | Discrete(3): 0 (ліворуч), 1 (нічого), 2 (праворуч) |
| **Винагорода** | -1 за кожен крок до моменту досягнення цілі |
| **Умова завершення** | Підйом вільного кінця вище лінії або 500 кроків |

## Технічний Стек

Проєкт побудований на сучасних інструментах для досліджень у сфері штучного інтелекту:
* **Python 3.10+**
* **PyTorch** — для побудови та тренування нейронної мережі.
* **Gymnasium (OpenAI Gym)** — середовище симуляції фізики.
* **NumPy** — для математичних обчислень.
* **Matplotlib** — для візуалізації графіків навчання.

## Путівник по Ноутбуку (Project Roadmap)

Проєкт розбитий на 6 логічних етапів, кожен з яких супроводжується детальним описом у форматі Markdown:

1.  **Налаштування:** Ініціалізація середовища та перевірка GPU (CUDA).
2.  **Архітектура DQN:** Створення "мозку" агента — нейромережі та системи пам'яті (Replay Buffer).
3.  **Тренування:** Запуск циклу навчання (300 епізодів), де агент вчиться на своїх помилках.
4.  **Аналіз результатів:** Побудова графіків сумарної винагороди та ковзного середнього.
5.  **Оптимізація:** Проведення експерименту з іншими гіперпараметрами (Learning Rate та Epsilon Decay).
6.  **Висновки:** Підбиття підсумків щодо ефективності обраного методу.

## Результати Навчання

Завдяки алгоритму DQN, агент проходить шлях від хаотичних рухів до ідеальної стратегії:
* **Початок:** Середня винагорода -500 (агент не встигає піднятися).
* **Фінал:** Середня винагорода стабілізується на рівні -80...-120 (завдання виконується за мінімальну кількість кроків).
