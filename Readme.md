# Аналіз тональності тексту на наборі даних IMDB
### Дослідження нейромережевих архітектур BiLSTM, 1D-CNN та механізмів Attention

Даний проєкт присвячений порівняльному аналізу ефективності різних архітектур глибокого навчання для задачі бінарної класифікації тексту (визначення позитивних та негативних відгуків на фільми). Експерименти проведено на повному наборі даних IMDB (50 000 записів).

## Використані бібліотеки та технології

Для роботи скрипта необхідно встановити наступний стек технологій:

* **torch** — основний фреймворк для розробки нейронних мереж.
* **datasets** — бібліотека від Hugging Face для завантаження та менеджменту даних.
* **gensim** — інструментарій для завантаження попередньо навчених векторних представлень слів (Word2Vec, GloVe).
* **scikit-learn** — розрахунок метрик (F1-score, Confusion Matrix).
* **matplotlib, seaborn** — бібліотеки для візуалізації результатів та побудови графіків.
* **numpy, re** — обробка числових даних та токенізація тексту.

## Структура та етапи розробки

Проєкт реалізований у форматі Jupyter Notebook і складається з наступних послідовних етапів:

1. **Попередня обробка даних:** Завантаження 25 000 тренувальних та 25 000 тестових записів. Побудова словника токенів із фільтрацією за частотністю (мінімум 5 входжень).
2. **Базова модель BiLSTM:** Реалізація двонаправленої рекурентної мережі з двома шарами LSTM та Dropout для регуляризації.
3. **Пайплайн навчання:** Створення універсальних функцій для тренування та оцінки моделей із фіксацією Loss, Accuracy та F1-score.
4. **Згорткова мережа (1D-CNN):** Використання паралельних згорткових фільтрів різних розмірів (3, 4, 5) для пошуку локальних емоційних патернів у тексті.
5. **Механізм Уваги (Self-Attention):** Інтеграція шару уваги в LSTM для покращення роботи з довгими реченнями та візуалізація ваг уваги у вигляді теплових карт.
6. **Transfer Learning:** Експериментальне порівняння результатів при використанні заморожених векторів GloVe та Word2Vec.
7. **Фінальна аналітика:** Побудова графіків навчання та матриць помилок (Confusion Matrix) для порівняння всіх архітектур.

## Основні результати експерименту

* **Найкраща архітектура:** Одновимірна згорткова мережа (1D-CNN) продемонструвала найвищу точність (>84%) та найменшу схильність до перенавчання.
* **Роль Attention:** Механізм уваги суттєво підвищив якість роботи LSTM (з 69% до 80%), дозволивши моделі фокусуватися на ключових словах-маркерах.
* **Обмеження Transfer Learning:** Використання універсальних попередньо навчених словників без донавчання (Fine-tuning) показало низьку ефективність (54-60%), що доводить необхідність адаптації векторів під специфічний домен кіновідгуків.
